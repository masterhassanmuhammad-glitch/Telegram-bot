# 🏥 MedicalBot

بوت تيليجرام طبي احترافي مبني بـ Python + TeleBot + PostgreSQL.

## 🚀 Features

- 📂 نظام أقسام (Menu Tree)
- 📄 رفع ملفات طبية (PDF / Images / Videos)
- 👥 إدارة المستخدمين (block / unblock / list)
- 📢 Broadcast لجميع المستخدمين
- 🩺 نظام استشارات طبية (Consultation system)
- ⚙️ لوحة تحكم أدمن كاملة
- 🔐 صلاحيات أدمن
- 🌐 Webhook جاهز لـ Render

---

## 🛠️ Tech Stack

- Python 3.10+
- pyTelegramBotAPI
- Flask
- PostgreSQL
- Render Hosting
